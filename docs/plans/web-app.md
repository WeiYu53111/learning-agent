# React Web 内容与关联知识查看

方案日期：2026-10-26；实施日期：2026-10-27。状态：**已完成（第一版）**。

第一版提供个人本机使用的只读检查工作台。查看教材原文、提取结果和已有知识关系；不启动模型、不修改内容。发现、补充和管理关联安排在后续版本。

## 1. 技术与运行

- React、TypeScript、Vite、React Router、TanStack Query；局部关系图使用 React Flow。
- FastAPI / Uvicorn 提供 `/api` 只读接口，复用现有模型、知识点编号映射及 SQLite 数据。CLI 继续保留。
- 前端在 `web/`，构建到 Python 包的 `web_static/`。运行时不需要 Node.js；源码安装需先构建，打包 wheel 前也需构建。
- `teach web --port 8765` 沿用 `--data-dir` / `TEACH_DATA_DIR`，仅绑定 `127.0.0.1`；Ctrl+C 停止。缺少前端资源时提示构建步骤，API 仍可用于 Vite 开发。
- 启动和请求不初始化或迁移数据库、不持有写锁。每次请求使用短时只读事务，允许与 CLI 提取同时使用。

## 2. 第一版内容

### 内容与原文

按教材、索引和章节浏览，默认选择最新索引并将选中版本固定在 URL。显示章节摘要、内容清单、知识点、内容类型、对应关系及数量，支持当前章节关键词和类型筛选。

点击引用定位原文文本块，显示 PDF 物理页码并高亮唯一逐字引用；引用不匹配、匹配不唯一、原文缺失均明确提示。支持原文翻页，不提供内嵌 PDF 阅读器。模型和原文文本不作为 HTML 执行。

已就绪索引读取快照；未完成索引仅投影成功保存的提取批次，复用原有编号映射并标记阶段结果。被拒绝候选不混入有效结果，分层中间摘要不作为最终摘要。

### 关联知识

- 独立展示前置知识、后续依赖、相关知识，包含理由、章节和跨章跳转。
- 两端知识点引用标为“知识点原文依据”，不冒充模型提供的关系专属证据。
- 一跳局部关系图：前置、当前、后续分列，相关知识另列；重复节点合并，多种关系保留。先修有向，相关无向。图与列表均可切换选中知识点。
- 对已有候选记录区分已确认关联、已检查未建立关联、尚未检查。没有候选记录的配对状态未知，不推断为无关系。
- 显示全书与当前章节已有任务的覆盖。候选检查完成不代表潜在关系完备。
- 关系与检查记录严格限定选定索引，旧数据库缺表时明确展示覆盖未知。

### 状态与导航

URL 保存教材、索引、章节和知识点，支持刷新恢复、前进和后退。手动刷新保留选择并显示读取时间。显示检查点数量、最近记录阶段和历史失败，不推测运行中状态或完成百分比。空数据、无文本页及缺失关系端点均有提示。

## 3. 查询接口

均为 GET，只提供展示所需响应模型，不暴露认证配置、任意文件或原始数据库行。

| 路径 | 用途 |
| --- | --- |
| `/api/books` | 教材列表；不存在数据目录时返回空列表，不创建目录 |
| `/api/books/{book}` | 教材信息、章节与索引列表 |
| `/api/books/{book}/sections/{section}?index=...` | 章节内容、状态与覆盖；未指定索引默认最新 |
| `/api/books/{book}/points/{key}?index=...` | 指定索引中的知识点、一跳关联及候选检查记录 |
| `/api/books/{book}/pages/{page}` | 单页解析文本和不可读取状态 |
| `/api/books/{book}/chunks/{chunk}` | 引用的原文文本块 |

按章节、页面和局部关系加载；无效教材、章节、索引、知识点与引用返回明确错误。接口不调用业务写入口，不依赖模型后端配置。
