# 全书知识梳理与按需学习调整方案

方案日期：2026-10-23；最后核对：2026-10-23。

状态：**已实现待验收**。功能已实现并完成模拟后端及离线 CLI 验证；真实教材的语义质量与耗时对照尚未完成。以下命令已接入 CLI。

剩余事项：完成第 7 节的真实教材对照并记录质量、调用次数及耗时。当前优先级见[计划总览](README.md)，跨方案待验收项见[待办清单](backlog.md#真实教材与评分评估)。第 7 节实施顺序保留为原交付过程，不代表三个增量仍待开发。

## 1. 目标与整体流程

将“指定范围后一次生成全部教学内容”调整为：

**导入 PDF → 梳理全书知识结构 → 选择章节学习或自由提问 → 按需生成教学内容并保存。**

全书梳理不提前生成所有题目。章节教学分为教学结构与练习设计两个阶段，减少返工范围，并支持独立恢复。

```bash
teach index BOOK
teach outline BOOK
teach learn BOOK --section s5
teach ask BOOK --text "为什么修改工具顺序会影响缓存？"
```

学习会话内支持 `/ask 问题`。回答结束后回到原题，保留已输入答案，不提交作答、不触发评分，也不更新掌握状态。

## 2. 全书知识结构与原文索引

导入仍只做本地解析，保存原文、章节、PDF 物理页码和文本块，同时建立本地检索索引。`teach index BOOK` 才调用模型梳理全书。

- 按章节和原文字符预算分批提取内容清单、知识点、原文引用与候选前置关系，不生成题目。
- 先汇总各章，再基于章节摘要整理全书关系。汇总超出请求预算时继续分组，不截断材料。
- 每个知识点保留稳定 ID、所属章节、简要说明及原文位置。跨章同类主题建立关联，保留各处原文记录；必要前置关系不得成环。
- 校验原文引用、文本块覆盖、ID 和关联。失败最多自动纠正一次，仍失败则保存候选并暂停。
- 分批保存结果，重复执行命令恢复未完成部分。完整校验通过后，才启用新的知识结构版本。
- `teach outline BOOK` 展示章节、知识点及梳理状态。无法读取的页明确列出，不宣称完整覆盖；第一版不增加 OCR。

## 3. 前置知识与用户自报掌握

进入章节时，列出尚无掌握记录的必要前置知识，提供三种选择：

| 选择 | 行为 |
| --- | --- |
| 补学 | 进入对应章节的学习入口 |
| 我已掌握 | 标记选定知识点或整章知识点，继续当前章节 |
| 本次跳过 | 仅在当前学习会话跳过，不建立长期掌握记录 |

“我已掌握”持久保存为**用户自报已掌握**，后续学习复用，不要求先做验证题。它与练习评分得到的“已验证掌握”分别展示。

- 整章标记覆盖当前知识结构版本下该章全部知识点；新版本新增或实质变化的知识点不自动继承。
- 自报记录与评分证据分开保存，不生成虚假作答、分数或已验证掌握记录。
- `outline` 展示自报状态；教学进度保留真实练习状态，并附自报标记。
- 用户可以撤销自报，撤销不删除已有练习或评分记录。
- 后续练习显示薄弱时，展示“自报掌握，但练习显示需复习”，允许继续学习并提示补练。
- 自报和跳过只影响学习安排，不删除知识点、不改写目标依赖，也不降低评分标准。

自报掌握管理命令：

```bash
teach mastery BOOK --section s4 --mark
teach mastery BOOK --point POINT --mark
teach mastery BOOK --section s4 --clear
teach mastery BOOK --point POINT --clear
```

`--section` 与 `--point` 二选一，`--mark` 与 `--clear` 二选一。整章操作前展示范围与知识点数量，交互入口明确确认后保存。

## 4. 按章两阶段生成教学内容

`teach learn BOOK --section SECTION` 使用可用的全书知识结构。尚未完成梳理时，提示先执行 `teach index BOOK`，不隐式启动全书长任务。

### 第一阶段：确定教学结构

根据所选章原文、全书关系及相关前置知识，细化内容清单、学习目标、误区与目标依赖。覆盖、引用和依赖校验通过后保存。

默认只学习所选章。跨章必要前置知识单独展示，提供补学、自报掌握和本次跳过入口，不自动扩大范围，也不默认用户已掌握。

### 第二阶段：生成练习

按目标组生成代表题、参考答案和评分标准。每批获得全局目标摘要、相关前置目标及对应原文；题目与评分标准一起生成，降低题干要求与扣分条件不一致的风险。

每次只返回该组题目，不允许修改第一阶段的目标或关系。程序校验目标组完整性，拒绝遗漏、重复或越界目标；校验通过后保存。

所有目标组完成后，组装现有 `Draft`，沿用完整审核、最多两轮修订、用户确认、发布和教学流程。相同书籍、知识结构版本及章节优先恢复或复用；使用 `teach learn BOOK --section SECTION --new` 显式重新生成。

出题失败只恢复失败目标组，不重新梳理全书。结构变化后的产物应作为新版本处理，不覆盖已发布教材或旧会话。

## 5. 教材内自由提问与跨章节处理

独立 `teach ask` 和会话内 `/ask` 共用单次问答流程。第一版限定当前教材，不联网补充，不引入独立多轮问答历史。

- 从问题、章节标题和知识点说明检索相关原文。采用本地中文字符片段与英文词项检索，不依赖嵌入服务或向量数据库。
- 将命中的原文及邻近上下文按输入预算交给模型。知识结构用于定位，原文用于支撑答案。
- 答案附 PDF 物理页码和可核验引用。引用失败最多纠正一次，仍失败不显示为有效答案。
- 依据不足时明确说明，不将“未检索到”表述成“整本书绝对没有”。
- 保存问题、检索证据、有效答案及后端信息，与作答、评分记录分开。
- 原文导入后即可提问；全书 AI 梳理未完成时，使用原文索引回答，并提示知识结构未完成。
- 提问、阅读讲解不自动计为已学习或已掌握。

### 不相邻章节与尚未学习章节

区分三个独立状态：已梳理知识结构、已准备教学内容、用户已学习或掌握。尚未学习不意味着系统尚未梳理。

当问题涉及第 2、6、9 章时，系统跨章定位证据，围绕问题解释关联并分别标注出处。检索范围不受用户已学章节限制。对尚未学习但理解答案必需的概念，提供简短说明，不自动展开整章课程。

回答后可以提示相关章节的学习入口，由用户决定是否进入。此次问答不会自动生成三个章节的练习，也不会标记这些章节已学或已掌握。

若全书梳理尚未完成，则仅对检索命中的原文做回答所需的局部理解，不在后台自动触发整章梳理；证据不足时明确说明。**提问触发检索与解释，选择章节学习才触发该章教学准备；全书梳理由显式 `index` 命令触发。**

第一版本地检索可能遗漏同义表达，测试须覆盖中文问题、英文术语和跨章问题，不承诺回答所有教材内问题。

## 6. 数据、兼容与恢复

- 增量迁移数据库，新增书籍级知识结构版本、阶段检查点、检索与问答记录，以及用户自报掌握记录。
- 教学版本绑定生成时的知识结构版本。新知识结构启用后，旧教学版本和学习进度保持原有绑定。
- 现有 `draft`、`prepare`、`start`、`resume` 继续可用。旧草稿按原流程恢复，不自动改写或重新生成；已有教材、会话、作答与评分完整保留。
- 第一版保持串行处理，先验证两阶段质量和恢复能力，不同时引入并发。
- 每阶段显示批次、等待时间、输入输出大小和缓存复用情况，保存模型调用耗时、后端及失败原因。

## 7. 实施顺序与验收

分三个可独立验证的增量交付：

1. 全书知识结构、原文检索、存储迁移与断点恢复。
2. 按章两阶段生成、前置知识选择、自报掌握管理及现有教学流程衔接。
3. 独立提问与学习中的 `/ask`。

验收场景：

- 多章节、重复主题、跨章依赖、无目录 PDF 和不可读取页面。
- 各阶段失败后的恢复、缓存复用、旧数据库与旧会话兼容。
- 出题不得改动目标；遗漏、重复及越界目标返回必须拒绝。
- 自报掌握持久复用、撤销、整章标记和版本变化；本次跳过不影响其他会话。
- 自报不伪造评分、不覆盖后续练习证据，也不降低评分标准。
- 跨章提问正确引用原文；未学习章节可参与回答，但不自动触发整章梳理、出题或掌握更新。
- 依据不足或引用纠正失败时，不输出无依据的有效答案。
- `/ask` 前后原题、答案缓冲及掌握进度不变。
- 使用此前 PDF 页 48–59 对照覆盖情况、引用错误、题目评分一致性、调用次数和总耗时。自动测试使用模拟后端；真实模型对照单独运行，不以“必然更快”作为拆阶段的保证。

现有实施背景见[实施与验收](archive/initial-implementation.md)。

- `book_learning.py` 编排可恢复的索引、章节结构、题目生成与问答；`book_models.py` 定义独立契约；现有 Draft 和旧提取路径保持兼容。

- 索引知识点 ID 根据章节、标题和原文块生成，不依赖模型返回顺序；自报掌握额外绑定内容指纹。关系按有界知识点摘要组配对检查，避免一次发送全书；书籍越大，关系分析调用次数可能越多。
- 教学结构按批生成，全部完成并通过整章校验后才开始出题。跨章前置用于进入会话前的选择；同章前置映射到目标依赖。题目包不能更改教学结构。
- 当前本地检索使用中文单字/双字及英文词项，按命中原文、知识点说明、章节标题排序，最多选取 8 个直接命中并补充邻近上下文，总原文预算 22,000 字符；这不是语义检索或完整性保证。
- 自由问答为单次问题，不传递学习答案或独立多轮聊天历史。成功、依据不足及失败问答均独立留存，错误引用不会作为有效答案输出。
- 自动测试覆盖分批恢复、旧数据迁移、整章结构先于出题、错误引用纠正、目标遗漏或重复、跨章问答、自报掌握及插问不修改会话。使用离线演示后端验证实际 CLI 入口，不调用真实模型。
- PDF 页 48–59 的真实语义质量与性能对照未运行；不宣称两阶段生成一定更快。
