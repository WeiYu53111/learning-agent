# 知识点提取优化与旧流程退役

方案与核对日期：2026-10-27。

状态：**已实现待验收**。新流程是唯一可执行的知识点提取流程；自动化测试和小样本验证不等于整本真实教材验收。首次提取质量是验收重点，不以知识点数量下降替代内容完整性。

## 1. 目标与范围

解决目录与出版信息被当成知识、同一概念按句拆散、批次上下文不足、跨批重复以及失败后重复处理的问题。

知识点按具有独立学习价值的概念、原理或方法划分。定义、性质、条件、解释和普通例子通常共同支撑一个知识点；有独立步骤和应用价值的方法可另成点。一个知识点可对应多条内容清单及多个学习目标。既不按句划分，也不强制整节合成一个点。

新版流水线标识为 `semantic-v1`。不保留旧提取开关、旧模型 `extract` 操作或旧检查点恢复路径。旧已保存内容只供历史查看，不用于新索引、新课程或新掌握状态的初始化。

首版不做跨章合并、OCR、自动迁移旧掌握状态，也不预设每章知识点数量。跨章联系通过知识关系表达。

## 2. 新流程与数据契约

### 2.1 原文角色与结构分析

保留原始 PDF、文本块 ID、页码和文本，不删除原文。新导入保存完整书签层级；老导入缺少层级时按需读取 PDF 书签，不重新解析全部正文。

模型在提取前分析编号的原文行/长行片段，返回连续区间、内容角色、小节路径、主题和分类理由。程序将区间转为原始 chunk 的字符偏移，并验证每个输入单元被完整且唯一分类。分类分批时携带前一批结构信息。

| 角色 | 处理 |
| --- | --- |
| teaching | 保留讲解、原理、步骤、条件、例子和练习 |
| navigation | 排除印刷目录、页码导航、重复页眉页脚；仍保留原文和理由 |
| publication | 排除封面、版权、出版说明、致谢等 |
| unknown | 保守保留，不能因不确定而删除 |

前言按内容判断，同页可以混合多种角色。目录条目不得作为正文证据；印刷页码不得未经验证当作 PDF 物理页码。章标题和小节标题应与相应正文一起保留。

### 2.2 语义批次规划

在分类与结构分析完成后，优先以小节路径和主题边界规划提取批次；连续同一主题允许跨多个原文块。默认正文与区域信息合计预算不超过约 10,000 字符，并按后端 `input_chars` 留出审核、Schema 和纠错空间。

每段正文仅有一个负责批次。前后各提供一个相邻教学区域作为参考，每侧最多 1,600 字符，独立标记为 `reference_context`，不得单独提取或引用。无法继续沿语义边界拆分时利用既有原文块边界；原始长行按上限切分，但保持坐标连续。

批次规划持久化，恢复不重新规划。新流程要求后端 `input_chars >= 16000`；仍超过后端预算时明确失败并保留已完成步骤，不截断原文冒充完整处理。

### 2.3 概念驱动的首次提取

输入包括章名、小节路径、主题、本批负责区域、原文块与参考上下文。模型先确定核心概念、原理或方法，再建立内容清单映射。

提示词同时给出正反例：栈的定义、后进先出特点、叠盘子类比应集中；括号匹配是独立方法。既避免普通例子独立成点，也避免把栈概念及多个应用算法强行合为一点。

`Navigation` 允许零知识点；纯非教学章节直接完成排除，不调用知识提取。`NavigationItem` 增加由程序规范化的稳定条目标识。最终索引保存 `pipeline`、`regions`、知识点、内容清单、摘要和关系。

确定性校验覆盖：引用逐字匹配且唯一；不得引用负责区域外文本；知识点及内容映射有效；正文区域的非空白文字均有清单证据。语义完整性仍由独立审核判断，不能仅凭引用覆盖断言完整。

### 2.4 质量审核与有限修订

每个首次提取批次独立审核过度拆分、过度合并、遗漏、无依据内容和错误映射。问题包含具体对象、修改建议及证据，无问题返回空列表。

有问题时进行一次定向修订并复审。修订可调整知识点划分或补充遗漏，但不得丢弃已提取的内容证据。复审仍失败则暂停，不发布、不循环修订。复审结果持久保存；查明原因或调整规则后用 `--new` 开始新的尝试。

确定性输出错误最多自动纠正一次。传输失败不盲目重试；保留先前有效的失败候选与错误，恢复时继续修复。缓存读取重新校验契约及引用要求。

### 2.5 跨批边界、摘要与关系

以相邻知识点及词项相近知识点生成有限候选，只审查不同批次之间的候选对。模型结合标题、描述和原文证据判断是否属于同一概念；词项匹配不自动建立合并。

归并仅改变知识点组织，程序保留全部内容清单和引用并重映射关联；变化后的分组重新进行语义审核。不跨章合并。对最终知识结构生成章节摘要和前置/相关关系，不复用旧提取结果对应的关系检查点。

## 3. 全量重建、按章重建与旧数据

```powershell
teach index BOOK
teach index BOOK --new
teach index BOOK --section SECTION --new
teach index BOOK --section SECTION
```

- 普通全书命令恢复新版全书未完成任务，或复用已完成的新版索引。只有旧索引时创建新版。
- `--new` 无条件新建，不被旧或新的未完成任务截获。
- 指定章节默认补齐从开头到目标章，无需全书基线；只有配合 --new 才重建目标章。其他已审核章节的知识点、清单、分类和摘要复用自绑定的基线，缺失前序章节依次补齐。
- 只重新分析涉及目标章的候选知识关系，其他章之间的既有关系保留。恢复时继续同一基线，不临时改用较新索引。
- 所有步骤和检查点绑定独立索引 ID，并含新流水线命名空间。旧任务不恢复、不自动删除。
- 内容完成程序与模型审核后保存独立的 content-ready 快照；学习入口使用最新审核完成的 semantic-v1 内容。全书候选关系完成才将索引标为 ready；关系失败不撤销内容就绪。指定章节仅声明截至该章的候选覆盖，不声明全书完成。
- 全书重建生成新的知识点身份，不继承旧掌握状态。按章重建保留未变化章节的 ID，自报记录可继续匹配；改变章节不自动迁移。
- 已生成旧课程仍可历史查看及继续既有会话；未完成旧课程不能继续旧提取流程，应创建基于新版索引的课程。

`draft` 不再直接调用旧 `extract`，而是绑定新版索引并执行教学结构、题目两阶段生成。真实教材没有新版索引时，明确要求先执行 `index`，不隐式启动整本 PDF 的长任务。仅内置离线演示自动建立其小型演示索引。

## 4. 下游教学与 Web

纯排除文本块不进入教学生成和后续校验；混合块提供区域清单，有效学习目标不得引用已排除文字。知识点和目标维持一对多关系。

Web 默认选择新版索引；旧版可显式选择并标为历史。未完成索引仅展示通过章节审核的知识点，不把未审候选当作最终结果。新增审核状态与排除内容/理由展示，原文浏览保持可用。

## 5. 验证与剩余验收

自动化验证包括分类覆盖/重叠、混合页原文坐标、unknown 保守保留、区域外引用拒绝、审核有限修订、恢复不重跑成功步骤、归并保留全部证据、旧版本隔离、全量不继承掌握状态、按章重建及 Web 投影。

`tests/fixtures/semantic_cases.json` 保存 12 类人工验收样本及预期，涵盖目录、版权、封面、前言、定义与例子、独立方法、条件、同句多概念、混合页、记号、跨段解释及练习。

真实模型评估命令：

```powershell
.venv/Scripts/python.exe -X utf8 scripts/evaluate_semantic_extraction.py --case mixed_frontmatter
# 所有样本会产生更多真实模型调用：
.venv/Scripts/python.exe -X utf8 scripts/evaluate_semantic_extraction.py --case all
```

评估使用独立的 `tmp/semantic-evaluation` 数据目录，保留原文、首次提取、最终结果和每次调用耗时/规模。重复同一命令恢复，`--new` 重跑。该工具不自动声称语义正确，需人工对照样本预期检查。

最终验收要求：首次提取已正确组织关键概念与方法；目录不产生知识；教学细节和证据没有丢失；后续审核及归并没有掩盖首次输出问题。记录真实调用成本。前两章实验 PDF 的完整验收和 12 类样本的全量真实模型对照仍需单独执行，不自动处理用户整本教材。

### 跨批归并审核的恢复

归并后的局部审核若发现问题，会保留失败报告，针对该审核涉及的知识点和清单进行一次定向修订，再复审。修订必须保留已有清单的全部原文证据，合并后仍执行整章引用、覆盖和映射校验；未涉及内容保持不变。章节预告可作为背景关联到适当知识点，不应提升为原文未讲解的独立概念。

修订和复审均保存检查点。旧任务停在 `boundary-verify` 时，重复原索引命令即可进入局部修订，无需 `--new`；修订或复审网络失败可继续恢复。复审仍未通过则暂停，不发布内容、不无限重试，需检查原因后再显式重建。

### 更新：跨页模型批次
