## 1. 当前问题与代表案例

### 评分偏重表达形式，未充分识别语义证据

- 学习者回答 `report_id: "007" 不能用数字7, format: "pdf" 需要改成小写，枚举值是小写的pdf`，已给出正确字段、取值和约束依据，却因未写成完整 JSON 对象、未重复前导零及 description 的局限等说明，被评为 67.5 分。该题没有明确考查严格 JSON 语法，部分额外解释还是题干已给前提。之后人工发起模型复核，最新评分为 100 分。
- 另一题已说明新配置由开发者提交、具体调用在模型响应中生成，学习者回答“新配置是tools,响应的具体调用是tool_calls”。模型未充分考虑这些名称的上下文指代，因未再次复述来源扣分，整题得 75 分。
- 同一题中“符合参数约束……只是参数的值不正确”的补充评价缺乏题内依据，但评分记录明确未因此扣分，应与第一问的争议区分。

这里的问题并不意味着所有简短回答都应通过：若缺少题目明确要求的核心推理，或表达存在实质歧义，仍需要补充证据。

### 刚性通过规则放大评分偏差

旧版模型对每个评分项只返回 `0 / 0.5 / 1`，程序要求加权总分至少 0.8 且所有关键项满分。`critical` 当前默认值为 `True`。若模型将补充说明也列为关键项，或把等价表达误判为部分正确，细小表达差异就可能使整题未达标。

### 达标计数清零容易造成进度丢失的感受

旧版 `independent_passes` 表示最近一次有效独立失败之后，不同场景的独立达标次数，并非历史累计通过次数。旧规则下，一次新的独立失败会清空本轮计数。因此此前为 `1/2`，随后一次未达标可能变成 `0/2`；历史通过记录仍然存在，并未删除。

此行为来自旧规则，不是数据库丢失作答。新版已改为明确独立失败减一次，最低为零；规则细节见第 4 节。

### 提示维护和验证方式不足

记录时评分提示仍嵌入 Python 代码，针对实际误判不断追加规则和具体例子。2026-10-22 已将提示文本迁移到包内文件，保持发送内容不变。仅增加提示长度或独立管理文件不能证明模型会在其他题目上稳定、公平评分。现有自动化测试主要验证结构、状态和数据一致性，不等于真实模型语义评分质量评估。

旧作答继续采用 v1 分数及进度规则；显式复核沿用该作答的规则版本，通过新增修订更新投影，不覆盖原记录。旧、新证据按原作答时间顺序重放。提示调整尚缺系统性的真实模型回归验证，不能宣称已彻底解决误判。离线演示仅用于流程验证，关键词未匹配按证据不足处理，不代表语义评分。

### 用能力证据形成题目结论

实施状态：已实现 v2。模型依据固定 rubric、学习目标快照和回答证据逐项返回 `met / incorrect / insufficient`，附原句及理由。题目或依据有问题时返回 `invalid_question`，无法可靠评价时返回 `needs_review`。目标不得用于追加题外要求。

程序只根据核心项汇总：全部满足则通过；存在明确错误则补练；仅证据不足则追问。数值分数退出新版通过判定；rubric 权重为兼容字段。

本题结论与目标掌握分开：模型负责解释本次证据，程序负责校验、保存，并综合独立性、不同场景、提示和误解等证据决定目标状态。仅将加权分数替换成模型布尔值不能保证公平，出题质量和评估集仍必需。

### 局部追问流程

实施状态：已实现，最多两轮，每轮一个问题。

当前流程：

```text
提交整题 → 评价能力证据
  ├─ 已证明核心能力 → 本题通过
  ├─ 明确知识错误 → 针对性讲解和补练
  ├─ 基本正确但证据不明确 → 聚焦缺失点追问 → 合并原回答和补充回答再判断
  └─ 题目或评分依据有问题 → 无法评价，不计学习者失败
```

- 原回答已经足够明确时直接通过，不为走流程强行追问。
- 仅补问原题要求范围内的缺失点，保留已答对部分；每题最多两轮，每轮一个问题。
- 追问期间不显示待确认部分的答案，不新增失败次数，也不改变已有达标计数。
- 原回答和补充回答构成同一次作答，整题最终只计一次；中性追问未泄露答案且未使用提示时可作为独立证据，提供提示或讲解后按辅助练习处理。
- 达到追问上限仍不能确认时，应明确剩余缺口；证据不足与明确答错要区分，不能机械推断未掌握。
- 已增加等待补充回答阶段及追问记录，支持暂停恢复、输入取消和评分失败重试；交互继续使用文字输入和 `/end`。

追问期间不展示最终反馈和纠正答案。达到上限仍证据不足时结束本次评价，不扣减次数。使用提示会将最终证据标为辅助作答；请求讲解或跳过会结束当前答题流程。追问或评分进行中禁止历史复核，避免修订与补充回答交错。

## 4. 已实现的新版计数规则

- 不同场景的独立通过使有效次数加一；同一已通过场景不重复加分。扣减不释放场景去重记录。
- 一次独立作答存在明确核心错误，整题只减一次，最低为零；历史通过记录保留。
- 证据不足、无效题、待复核及辅助作答不扣减；辅助通过也不增加独立达标次数。
- 明确独立错误建立待补练缺口。即使有效次数仍达到两次，存在缺口时也不认定掌握。
- 新补练题必须声明缺口标识及覆盖它的核心要求。仅针对缺口的独立整题通过才能解除缺口，无关题通过不解除。
- 已确认关键误解继续使用原有单独解除规则。

规则按作答版本重放：v1 保留失败清零等旧行为，v2 使用上述规则。历史复核仍可通过最新有效修订改变投影，但不会自动将旧作答升级为 v2。
